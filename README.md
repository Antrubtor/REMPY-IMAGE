# REMPY - Geodesic Distance Transform

## Introduction

The goal of this project is to enable the visualization of comparative benchmarks between the implementation of the **Geodesic Distance Transform** algorithm in **pure Python** and in **Numba Python**.
The backend was built using the **FastAPI** framework with a **PostgreSQL** database and the frontend using **Streamlit**.

## Interface Guide

This app consists of three different interfaces.

### Home

This section is the app's home page, where you can send an image and a mask and then click on ‘Start Benchmark’ to obtain the results.
The images and masks are **saved in the database** after each benchmark, so that if the same combination of image/masks is reused, the app offers the option of viewing the results directly or rerunning the benchmark.

### Directory

This page allows you to **perform the benchmark directly on a folder or select multiple images**, then offers to **manually select the image/mask combination and the number of tests** to be performed, and those for each of the benchmarks to be performed, and then run the benchmark !

### History

The history allows you to **view all benchmarks already performed** and, if desired, click on ‘View Results’, ‘Run More Tests’ or ‘Delete’, which will remove this image/mask combination from the database.

### Results

This page, which is the most interesting, allows you to obtain and view **all the necessary statistics** and the results of Geodesic Distance Transform.

It shows the **average** calculation time, the **minimum and maximum** times obtained, and the **standard deviation** for **Python and Numba**, with a **Speedup column** that allows you to see the **Numba gain factor**.

It also displays **three comparative plots**: the first two use **bar plots** and **scatter plots** to visualize the execution times of the algorithm between Python and Numba. Finally, the **image generated by the Geodesic Distance Transform** function.
